# Feralis (front)

Sitio web de la revista digital como proyecto par Anima llamada "Feralis".

## Integrantes
- [Mauro Villarroya]
- [Mathias Richieri]
- [Carolina Pereyra]
- [Romina Bermudez]

## Descripción
Pagina principal con navbar, portada, cuatro temas y panel de contacto. 
Cada tema abre una página de artículo con su texto, imágenes e índice de palabras clave.

## Cómo correrlo
1. Clonar este repositorio al lado del repositorio del back, en la misma carpeta.
2. Iniciar el servidor del back (npm install y node index.js dentro de back).
3. Abrir http://localhost:3000.

Necesita internet para cargar Bootstrap y las fuentes de Google.
